# Questions for answers.md

## 1. What is Git?
Git is a free, open-source distributed version control system. It tracks changes to files over time and allows multiple developers to work on the same codebase simultaneously.

## 2. What is GitHub?
GitHub is a cloud-based platform used to store, manage, and share Git repositories online. It provides a visual interface for team collaboration, code sharing, and project management.

## 3. What is a repository?
A repository (or repo) is a digital storage space where Git tracks and manages all the files, folders, and historical changes of a project.

## 4. What is the difference between git clone and git pull?
- git clone: Copies an entire remote repository into a brand new local folder. You run this only once at the start.
- git pull: Fetches and merges updates from a remote repository into an existing local folder to keep it updated.

## 5. What is the difference between git commit and git push?
- git commit: Saves your staged changes locally on your own computer as a new project version snapshot.
- git push: Uploads your local commits to a remote server like GitHub so others can access them.

## 6. What information does git status provide?
It shows the current state of your working directory. It lists modified files, files staged for a commit, and untracked files.

## 7. Why should a project contain a README?
A README introduces the project, explains its purpose, provides setup instructions, and guides new contributors on how to use or edit the code.

## 8. Give four examples of files that should not be uploaded to GitHub.
1. Sensitive credentials (passwords, API tokens, private keys).
2. Environment variables (.env files).
3. Operating system system files (.DS_Store, Thumbs.db).
4. Large external dependency folders (node_modules).
